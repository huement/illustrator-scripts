## [1.0.0] - 2025-01-XX

### Added - FREE Version
- Initial release of AI Swatch Scripts FREE Version
- **SwatchLegend.jsx**: Generate professional color legend grids
  - HEX, RGB, CMYK, LAB value display
  - Automatic color naming with 27,000+ color names database
  - Sort by hue functionality
  - Customizable borders
- **Palette Template V2**: Professional color palette template
  - `palette-v2.ai`: Extended palette with gradients
  - Pre-built color systems with Bootstrap colors
  - Hover state variations
  - Complete grayscale palette
  - Ready-to-use gradient swatches
- **colornames.min.json**: Comprehensive color naming database
- Complete documentation with installation guides
- Bootstrap-based HTML documentation with screenshots
- Support for Adobe Illustrator CC 2019 and later
- macOS and Windows compatibility
- Prominent upgrade CTAs to full version on Gumroad

### Full Version Available
The complete package with all 4 scripts + 2 templates is available at:

Full version includes:
