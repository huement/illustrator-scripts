Locate the Scripts Folder

Navigate to your Adobe Illustrator Scripts folder using Finder:

/Applications/Adobe Illustrator [VERSION]/Presets/[LANGUAGE]/Scripts/

Example: /Applications/Adobe Illustrator 2024/Presets/en_US/Scripts/

How to Use the Scripts

🎨 Swatch Legend
  1. Select swatches in Swatches panel (or none for all)
  2. Run File → Scripts → SwatchLegend
  3. Choose options in dialog (HEX, RGB, CMYK, etc.)
  4. Click Generate

Result: Grid of color squares with detailed information

🎨 Swatch Shades
  1. Select swatches in Swatches panel
  2. Run File → Scripts → SwatchShades
  3. Configure shading amount in dialog
  4. Click Generate

Result: Horizontal strips showing 5 darker, original, and 5 lighter versions

💾 Swatch Export
  1. Select swatches to export
  2. Run File → Scripts → SwatchExport
  3. Choose formats (JSON, SCSS, CSS, etc.)
  4. Select color format (HEX, RGB, HSL)
  5. Choose save location

Result: Color files ready for web development

🔄 Swatch Transfer
  1. Open multiple Illustrator documents
  2. Make destination document active
  3. Run File → Scripts → SwatchTransfer
  4. Select source document
  5. Choose replace or duplicate option

Troubleshooting

  • Make sure you've restarted Illustrator after copying the script
  • Verify the file has a .jsx extension, not .jsx.txt
  • Check that the file is in the correct Scripts folder for your version of Illustrator
  • Try placing the script in the alternative user folder location

  • Make sure you have an open document with swatches
  • Select swatches in the Swatches panel before running the script
  • Check that your first layer isn't locked
  • Try creating a new document with some basic color swatches

Color conversions between different color spaces (RGB, CMYK, LAB) can result in slight variations. This is normal behavior due to different color gamuts.

  • HEX values are derived from RGB conversions
  • CMYK to RGB conversions may not be exact reversals
  • Check your document's color mode (RGB vs CMYK)

macOS: The Library folder may be hidden. Hold Option while clicking the "Go" menu in Finder to see the Library option.

Windows: You may need to show hidden files and folders:

  1. Open File Explorer
  2. Click "View" in the menu
  3. Check "Hidden items"

Swatch Legend Output Format

When using Swatch Legend, each generated swatch displays information in the following format:

Format Structure
[Swatch Name]
HEX #[RRGGBB]
R [0-255] G [0-255] B [0-255]
C [0-100] M [0-100] Y [0-100] K [0-100]
Example Output
Sunset Orange
HEX #FF6B35
R 255 G 107 B 53
C 0 M 58 Y 79 K 0
